## 🚀 Getting Started in 5 Minutes

1. **Read** [QUICK_REFERENCE.md](QUICK_REFERENCE.md) (5 min)

2. **Run tests locally:**
   ```bash
   mvn clean test
   ```

3. **View coverage:**
   ```bash
   mvn jacoco:report
   open target/site/jacoco/index.html
   ```

4. **Check CI/CD status:**
   - Go to Actions tab on GitHub
   - View latest test run

5. **Next steps:**
   - Read detailed guides as needed
   - Start writing tests

## 💡 Tips & Tricks

### Most Useful Commands

```bash
# Run all tests
mvn clean test

# Run with coverage
mvn clean test jacoco:report

# Run specific test
mvn test -Dtest=RoomServiceTest

# Skip tests
mvn clean install -DskipTests

# View coverage report
open target/site/jacoco/index.html
```

### Keyboard Shortcuts (GitHub)

- `g` → Go to Repository
- `?` → View keyboard shortcuts
- `c` → Create issue/PR

### IDE Integration

Most IDEs support running tests directly:
- IntelliJ: Right-click test class → Run
- Eclipse: Right-click test class → Run As → JUnit Test
- VS Code: With Test Explorer plugin

## ❓ FAQ

### Q: How often should I run tests?

**A:** Every time you make code changes. Our CI/CD pipeline runs automatically on push.

### Q: What's the minimum coverage requirement?

**A:** 60%+ overall, 85%+ for service layer. Current: 73.2%

### Q: How long do tests take?

**A:** Locally: ~45 seconds. In CI/CD: ~12-15 minutes (includes build).

### Q: Can I run tests without the database?

**A:** Yes, H2 in-memory database is used for testing (no external setup needed).

### Q: How do I debug a failing test?

**A:** See [troubleshooting section](QUICK_REFERENCE.md#-debugging-tests) in QUICK_REFERENCE.md

### Q: How do I add new tests?

**A:** See [test templates](QUICK_REFERENCE.md#-test-structure) and [patterns](TESTING.md#best-practices) in documentation.
